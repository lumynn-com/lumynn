# Redesign Priorities

Targeted redesign, not rewrite.

1. Reduce active CSS override pressure, especially `!important` in current mobile/surface/chrome layers.
2. Keep desktop IA discoverability visible in future work; do not hide core navigation only behind command menus.
3. Use one product palette and typography direction across dark and light themes.
4. Polish login, empty, and loading states before adding new surface styles.
5. Keep a Playwright screenshot guard for desktop/mobile visual regression checks.
