# Offline Roadmap

Backlog scenarios to consider after the first offline editing pass:

- Pin individual notes or folders for guaranteed offline access.
- Cache the full vault with user-visible storage usage and cleanup controls.
- Add conflict resolution that shows local/server diffs before choosing a version.
- Provide per-user cache management for notes, media, and queued writes.
- Support offline import/export snapshots for backup and migration.
- Add local search over cached notes while the server is unreachable.
